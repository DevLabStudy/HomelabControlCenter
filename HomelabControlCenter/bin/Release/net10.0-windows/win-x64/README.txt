==================================================
        DEVLAB HOMELAB CONTROL CENTER (CC)
==================================================

Opis aplikacji:
Zaawansowane narzędzie administracyjne stworzone dla administratorów sieci i pasjonatów homelabów. Łączy zarządzanie węzłami zdalnymi przez SSH, diagnostykę sprzętową WMI w formacie AIDA64, diagnostykę sieciową oraz bezpieczne uwierzytelnianie mobilne za pomocą generatora kodów QR.

Główne funkcje:
- Obsługa sesji SSH i interaktywny terminal zdalny.
- Skaner diagnostyczny WMI (CPU, RAM, GPU, płyta główna, dyski, sieć).
- Skaner podsieci oraz narzędzia sieciowe (Ping, Traceroute, iPerf3, fio, Port Scan, DNS Lookup).
- Generator tokenów bezpieczeństwa oparty na kryptograficznym algorytmie kryptograficznym.
- Nowoczesny interfejs w stylu Fluent Design (WPF-UI) z pełnym wsparciem trybu ciemnego.

Wymagania systemowe:
- System operacyjny: Windows 10 / 11 (lub nowszy, architektura x64).
- Środowisko uruchomieniowe: .NET 10 (lub .NET 8/9 z odpowiednimi bibliotekami zależności).
